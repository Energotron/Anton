# Game Design Document

## High concept
A story-driven space sandbox with a living galaxy, faction conflicts, text quests, trade, exploration, and emergent events.

## Pillars
1. **Living galaxy** — systems, factions, patrols, incidents.
2. **Meaningful travel** — route choice, risk, time, fuel, missions.
3. **Text quest legacy** — branching narrative quests with consequences.
4. **Player agency** — trade, combat, diplomacy, story choices.
5. **Humor + cosmic drama** — serious stakes with charm and irony.

## MVP vertical slice
- 8–12 star systems
- 3 factions
- player ship with stats
- docking and travel
- trade loop
- 10 text quests
- 1 main story arc
- 1 random event system
- reputation changes

## Core loops
### Travel loop
Take mission -> fly -> encounter event -> resolve -> dock -> get reward / consequence

### Economy loop
Buy low -> move cargo -> sell -> upgrade ship -> unlock riskier routes

### Story loop
Meet trigger -> accept quest -> branching choices -> world state changes

## Systems to implement later
- tactical combat
- companions / crew
- bounty hunting
- procedural contracts
- pirate and AI threat escalation
- planet-side quest modules

## Open decisions
- exact title
- visual style (retro 2D / modern 2.5D)
- combat mode for MVP
