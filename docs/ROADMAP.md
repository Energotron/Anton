# Roadmap — Дети Эльтана

## Phase 0 — Foundation
- зафиксировать конституцию проекта
- обновить GDD, lore, quest schema
- описать Smart Diplomacy System
- зафиксировать соло-кампанию как главный MVP
- держать online как отдельный контур, не размывающий scope

## Phase 1 — Lore & Systems Lock
- основной сюжетный каркас
- Келлер и его роль
- Дети Эльтана и гибридные расы
- Теневые Флоты
- Index of Discord
- Alliance Grid
- переговорные профили фракций

## Phase 2 — Vertical Slice (Solo)
- 8–12 систем
- карта галактики
- фракционная репутация
- базовая дипломатия
- 1 пролог
- 1 сюжетная арка с Келлером
- 1 гипер-миссия
- 1 теневая черная дыра
- 5–10 текстовых квестов

## Phase 3 — War Layer
- карта партизанской войны
- фронт Махпелл
- удары из гипера
- поддержка теневых флотов
- последствия решений на глобальной карте

## Phase 4 — System Deepening
- психологические профили лидеров
- сложные переговорные деревья
- секреты, шантаж, разведданные
- кризисы альянса
- самосборка коалиции и риск раскола

## Phase 5 — Online Foundation (separate track)
- гипер-арены
- PvE спецоперации
- кооперативные рейды
- клановые базы
- живой рынок
- ассистенты / NPC bots as optional support layer

## Monetization Guardrails
- no hard pay-to-win
- reward-based ads only where it doesn't destroy pacing
- cosmetics, convenience, light resource boosts
- solo campaign must remain complete and достойной без доната

## External testing loop
- Manus AI: scenario testing, logic validation, edge cases, dialogue branch breakage
