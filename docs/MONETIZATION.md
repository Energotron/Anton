# Monetization

## Principle
Монетизация не должна разрушать атмосферу, баланс и достоинство кампании.

## Allowed Directions
### Rewarded Ads
Только добровольные просмотры за умеренные награды.

Possible lore wrappers:
- кредиты Коалиции
- ноды Келлера
- ограниченная антиматерия Теневых Флотов
- разведданные

### Soft Donat
- косметика
- ускорение удобства
- визуальные стили кораблей
- флаги, клановые элементы, UI skins

## Hard Rules
- no hard pay-to-win
- no blocking core story behind payments
- solo mode must remain полноценным
- power items only in carefully controlled online economy, if ever

## Reward Ideas
- разведданные Келлера
- сниженный индекс локального кризиса
- разовый быстрый прыжок
- мелкие ресурсы на ремонт / logistics
